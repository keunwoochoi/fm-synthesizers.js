# Patches

The patch bank is the product (PRINCIPLES #1). Each patch ships a `patches/<id>/intent.md`
written before tuning — prose plus measurable targets derived from that prose — and the
exported preset id, the intent directory, and the intent heading must all agree. The
mapping is checked by `scripts/verify/check_intents.py`.
